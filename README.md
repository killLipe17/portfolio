## 🚀 Projetos em destaque

### 01 — SagaTrack

Aplicativo mobile para acompanhamento de maratonas cinematográficas com missões, quizzes, XP, níveis e conquistas.

**Destaques:**
- 38 filmes organizados por lançamento e cronologia
- 7 missões
- 114 perguntas de quiz
- XP, níveis, conquistas e temas
- Persistência local com AsyncStorage
- Integração com TMDB API
- Compartilhamento nativo
- Build Android com EAS
- Versão 1.0.0 em teste fechado na Google Play

**Tecnologias:** React Native, Expo, Expo Router, TypeScript, TMDB API, AsyncStorage, EAS e Google Play.

**Estudo de caso:**  
https://portfolio-seven-coral-t58e5zn2u9.vercel.app/projetos/sagatrack

### 02 — KILL LIPE

Site institucional e media kit desenvolvido para um canal de games, com integração à API do YouTube, métricas atualizadas e estrutura multilíngue.

**Destaques:**
- Métricas em tempo real
- Conteúdo em PT, EN e ES
- Integração com YouTube Data API
- Formulário de contato profissional
- Integração com Resend

**Tecnologias:** Next.js, TypeScript, Tailwind CSS, YouTube API, Resend e Vercel.

**Projeto:**  
https://kill-lipe.vercel.app/

### 03 — Guiart Games e Colecionáveis

Plataforma desenvolvida para uma loja de games e colecionáveis, com catálogo de produtos, gerenciamento de estoque e fluxo de pedidos.

**Destaques:**

- Controle de estoque
- Painel administrativo
- Pedidos via WhatsApp
- Banco de dados integrado

**Tecnologias:** Next.js, TypeScript, Tailwind CSS, Prisma, PostgreSQL e Supabase.

**Projeto:**  
https://guiart-web-nine.vercel.app/
